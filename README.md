# Automatic-File-Sorter

# Overview

This Python script automates the organization of files in a given directory. It sorts files into subfolders based on their file type, making it easier to manage large numbers of documents, spreadsheets, images, and PDFs.

This Python script automatically organizes files in a specified folder by type. It sorts files into subfolders for Excel (.xlsx), Word (.docx), PDF (.pdf), and image (.jpg) files.

The script creates folders if they don’t exist, moves files into the corresponding folders, and alerts the user about any files that don’t fit the predefined categories.

Requirements: Python 3 with standard libraries os and shutil.
